# Narat's Portfolio

A bilingual Khmer/English student developer portfolio built with React, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Run `npm run build` to create a production build in `dist/`.

The two project cards are placeholders until real projects are added. The student photo is in `public/images/narat-portrait.webp`.
Background music is in `public/audio/rat-music.mp3`. The site attempts to play it on load; browsers that block audible autoplay start it after a visitor interaction or through the music button.
